# 公开测试证据说明

此目录保存测试报告的公开副本，测试版本、环境与通过范围以各报告及索引为准。报告中的历史版本不自动代表当前源码或最终发行包已经通过。

公开整理仅替换个人主目录、仓库绝对路径、临时目录标识及私人环境地址，分别使用 `<home>`、`<repo>`、`<external-project>`、`<tmp>` 等占位符。占位符不是可以直接执行的路径；状态、结果、耗时、源码提交与原产物哈希保持原记录。

被脱敏的报告带有 `publicRedaction` 字段，保存整理时间和原文件 SHA-256。对应索引中的 `sha256` 校验公开副本，`originalSha256` 保留整理前的引用。原文件另存于维护者受控本地目录，不提交到仓库；没有把脱敏副本伪装成未经处理的原始回执。

账号凭据、Cookie、浏览器 profile、原始网页回执与操作日志不在此目录中。两张控制台截图是历史本机测试页面，展示的是当时界面，不代表最新版本截图。

更新公开副本不会清理既有 Git 历史。仓库可见性、历史内容审查和固定安装包验收仍是独立的发布步骤。
