# Public test evidence notes

[简体中文](README.md) | **English**

This directory holds public copies of test reports. Each report/index defines the tested version, environment, and passing scope. Historical versions do not automatically establish acceptance of current source or final packages.

Public preparation replaces personal home paths, absolute repository paths, temporary-directory identifiers, and private environment addresses with placeholders such as `<home>`, `<repo>`, `<external-project>`, and `<tmp>`. These are not executable paths. States, results, durations, source commits, and original artifact hashes retain their recorded values.

Redacted reports include `publicRedaction` with preparation time and original-file SHA-256. Index `sha256` verifies the public copy; `originalSha256` preserves the earlier reference. Originals remain in a maintainer-controlled local directory outside Git. Redacted copies are not presented as untouched raw receipts.

Account credentials, cookies, browser profiles, raw webpage receipts, and operation logs are excluded. The two console screenshots show historical local test pages, not the latest UI.

Updating public copies does not clean existing Git history. Repository visibility, historical-content review, and fixed-package acceptance remain separate release steps.
