# Project card

[简体中文](PROJECT_CARD.md) | **English**

- Product: laofu-browser, an independent browser execution and article/image capture service.
- Role: shared-capability support project; this delivery covers the independent service and integration packages, without changing other project roles.
- First user: Laofu (老傅); callers are the owner and internal products.
- Local MVP: complete original tool set, reliable tasks, article packages, console, and two SDKs accepted against a real service.
- Final completion: actual cross-system P5 verification and fixed deployment artifacts; unverified environments remain incomplete.
- Pause condition: do not open restricted-product access if execution isolation or unknown-effect handling fails; do not advance by bypassing the sandbox.
- Non-goals: external SaaS, model/payment platforms, CAPTCHA evasion, formal business-product integration.
